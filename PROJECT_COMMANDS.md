# PROJECT_COMMANDS.md

All commands assume your current directory is:

```bat
c:\Users\ddnan\intenrship_IIIT
```

## 0) Prerequisites (required)
- `SUMO_HOME` must be set and SUMO binaries (e.g., `sumo`, `sumo-gui`) must be on that install.
- Activate your environment (if you use one), then install python deps:
  ```bat
  pip install -r smart_city_ai\requirements.txt
  ```

## 1) Train RL agents (DQN / DDQN / PPO)
### Train DQN
```bat
python smart_city_ai\tools\enhanced_training.py --agent dqn --seed 101 --episodes 250
```

### Train DDQN
```bat
python smart_city_ai\tools\enhanced_training.py --agent ddqn --seed 101 --episodes 250
```

### Train PPO
```bat
python smart_city_ai\tools\enhanced_training.py --agent ppo --seed 101 --episodes 250
```

### Train multiple seeds (recommended)
```bat
python smart_city_ai\tools\enhanced_training.py --agent dqn --seeds 101 202 303 404 505 --episodes 250
python smart_city_ai\tools\enhanced_training.py --agent ddqn --seeds 101 202 303 404 505 --episodes 250
python smart_city_ai\tools\enhanced_training.py --agent ppo --seeds 101 202 303 404 505 --episodes 250
```

## 2) Run PINN prediction (PINN forward pass)
The project performs PINN inference inside hybrid runners and emergency controllers.

### PINN ablation study (with vs without PINN)
```bat
python run_pinn_ablation_study.py
```
Outputs:
- `results\pinn_ablation\pinn_ablation_report.json`
- `results\pinn_ablation\pinn_comparison_table.csv`
- `results\pinn_ablation\pinn_ablation_summary.txt` (if generated by your environment)

## 3) Run ACO routing
ACO is integrated into the emergency controller and into the RL+ACO hybrid integration.

### ACO + RL integrated simulation (all features via integration script)
```bat
python smart_city_ai\integration\rl_pinn_aco_integration.py --config smart_city_ai\sumo_network\config.sumocfg --pinn smart_city_ai\pinn_models\trained_pinn.pth --duration 2000 --enable-aco 1 --enable-pinn 1 --seed 42 --metrics-output-dir results\aco_results\checkpoints --run-name aco_all_enabled
```

### ACO + RL integrated simulation (ACO only: PINN off)
```bat
python smart_city_ai\integration\rl_pinn_aco_integration.py --config smart_city_ai\sumo_network\config.sumocfg --pinn smart_city_ai\pinn_models\trained_pinn.pth --duration 2000 --enable-aco 1 --enable-pinn 0 --seed 42 --metrics-output-dir results\aco_results\checkpoints --run-name aco_no_pinn
```

## 4) Run Emergency Corridor system
Emergency corridor coordination is executed via the emergency controller.

### Emergency corridor enabled + PINN enabled
```bat
python smart_city_ai\integration\run_emergency_system.py --config smart_city_ai\sumo_network\config.sumocfg --pinn smart_city_ai\pinn_models\trained_pinn.pth --duration 2000 --enable-corridor 1 --seed 42 --metrics-output-dir results\emergency_metrics --run-name emergency_corridor_all
```

### Emergency corridor enabled + PINN disabled (fallback)
```bat
python smart_city_ai\integration\run_emergency_system.py --config smart_city_ai\sumo_network\config.sumocfg --pinn smart_city_ai\pinn_models\DOES_NOT_EXIST.pth --duration 2000 --enable-corridor 1 --seed 42 --metrics-output-dir results\emergency_metrics --run-name emergency_corridor_no_pinn
```

### Emergency corridor disabled (baseline emergency)
```bat
python smart_city_ai\integration\run_emergency_system.py --config smart_city_ai\sumo_network\config.sumocfg --pinn smart_city_ai\pinn_models\trained_pinn.pth --duration 2000 --enable-corridor 0 --seed 42 --metrics-output-dir results\emergency_metrics --run-name emergency_no_corridor
```

## 5) Predictive Green Wave (PGW)
PGW is part of the emergency controller’s corridor activation logic:
- `HybridEmergencyController` uses `GreenCorridorManager` and PINN predictions.

To run PGW, run emergency system with:
- `--enable-corridor 1` (and provide PINN to enable predictive influence)

(See section 4.)

Traffic clearing is executed inside `HybridEmergencyController` and its `TrafficClearingSystem`.

To run traffic clearing, run the emergency system (section 4).
